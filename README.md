## ฟีเจอร์หลัก
- แบบประเมิน 6 แขนง (พลกาย / ปัญญา / จิตใจ / สังคม / อาชีพ / ทรัพย์) รวม 24 ข้อ คำถามเขียนแบบ
  psychology-style ชวนทบทวนจริง ไม่ใช่แค่เช็คลิสต์
- เลือกคลาสตัวละคร (นักรบ / นักปราชญ์ / โจร / นักบวช) + ตั้งชื่อตัวละครก่อนเริ่ม (*ใช้ Gemini ในการสร้างรูปภาพ)
- XP HUD, particle effect, floating `+XP`, หน้าจอ "ด่านผ่านแล้ว" พร้อมคำคมสุ่ม, คีย์ลัด 1-5
- เสียงเอฟเฟกต์สร้างสดด้วย Web Audio API (ไม่ต้องมีไฟล์เสียง) + เพลงพื้นหลัง mp3 ที่ใส่เอง
- หน้าผลลัพธ์: กราฟเรดาร์ 6 แกน, เลเวล (เส้นโค้งแบบไม่เชิงเส้น), ยศ/แรงค์, **ฉายาอาร์คีไทป์**
  (คำนวณจาก 2 แขนงคะแนนสูงสุด มีได้ 15 แบบ), จุดแข็ง/จุดอ่อน, ภารกิจแนะนำ 7 วัน
- บันทึกการ์ดผลลัพธ์เป็นรูปภาพ (PNG) และคัดลอกข้อความชวนเพื่อนเล่นต่อ
---
## Dependencies ภายนอก
โหลดผ่าน CDN ตอนรันจริง (ต้องมีอินเทอร์เน็ต):
- [Google Fonts](https://fonts.google.com/) — Cinzel, Cinzel Decorative, Noto Serif Thai, JetBrains Mono
- [html2canvas](https://html2canvas.hertzen.com/) (v1.4.1, จาก cdnjs) — ใช้ตอนกด "บันทึกการ์ดเป็นรูปภาพ"
ถ้าอินเทอร์เน็ตช้าหรือ CDN ถูกบล็อก: ฟอนต์จะ fallback เป็นฟอนต์ระบบ และปุ่มบันทึกรูปจะใช้งานไม่ได้
(ฟีเจอร์อื่นทั้งหมดยังทำงานปกติ)
---
## Browser support
ทดสอบและออกแบบมาให้ใช้กับเบราว์เซอร์รุ่นใหม่ (Chrome / Edge / Safari / Firefox เวอร์ชันล่าสุด)
ที่รองรับ Web Audio API, CSS `clamp()`/`grid`, และ `<audio>` element เป็นหลัก
