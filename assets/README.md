# โฟลเดอร์ assets/

วางไฟล์ของคุณตามชื่อ/ตำแหน่งด้านล่างนี้เป๊ะๆ แล้วเว็บจะดึงไปใช้เองอัตโนมัติ
(ถ้าไม่มีไฟล์ใดไฟล์หนึ่ง เว็บจะ fallback ไปใช้อีโมจิ/ไอคอนแทนให้อัตโนมัติ ไม่พัง)

## โลโก้
- ตำแหน่ง: `assets/logo.png`
- ใช้ที่: หัวเว็บ (แถบ "Codex of Self") และ favicon แท็บเบราว์เซอร์
- แนะนำ: ไฟล์สี่เหลี่ยมจัตุรัส พื้นหลังโปร่งใส ขนาดประมาณ 128x128px ขึ้นไป

## เพลงพื้นหลัง
- ตำแหน่ง: `assets/music.mp3`
- ใช้ที่: เล่นวนตอนอยู่หน้าควิซ/ผลลัพธ์ กดปุ่ม 🎵 มุมขวาบนเพื่อเปิด/ปิด
- แนะนำ: เพลงบรรเลงเบาๆ ไม่มีเนื้อร้อง วนซ้ำได้ลื่น (loop) ไฟล์ไม่ใหญ่เกินไปเพื่อโหลดเร็ว

## ภาพหน้าตัวละคร (portrait) ต่อคลาส
- ตำแหน่ง:
  - `assets/avatars/warrior.png`  (นักรบ)
  - `assets/avatars/sage.png`     (นักปราชญ์)
  - `assets/avatars/rogue.png`    (โจร)
  - `assets/avatars/cleric.png`   (นักบวช)
- ใช้ที่: การ์ดเลือกคลาส, มุมขวาบนตอนเล่นควิซ, การ์ดผลลัพธ์ตอนจบ
- แนะนำ: ภาพสี่เหลี่ยมจัตุรัส (1:1) เช่น 256x256px จะถูกครอปเป็นวงกลมอัตโนมัติ
- ถ้าไม่มีไฟล์เหล่านี้ เว็บจะโชว์อีโมจิไอคอนของคลาสนั้นแทนโดยอัตโนมัติ (ไม่ error)

## เปลี่ยน path ได้ไหม?
ได้ — ไปแก้ที่ `js/data.js` ในตัวแปร `CLASSES` แต่ละอันมี field `portrait` แก้ path ตรงนั้นได้เลย
